## 👨‍🏫 프로젝트 소개
본 프로젝트는 신발 제조업체의 효율적인 공정 관리를 위해 ERP와 MES 시스템을 통합하여 개발된 웹 기반 솔루션입니다.
ERP와 MES 시스템의 데이터를 통합하여, 인사 및 근태 관리부터 자재 발주, 재고 관리, 생산 계획, 작업 지시, 품질 관리에 이르는 제조 공정 전반을 실시간으로 통합 관리할 수 있도록 설계되었습니다.

## ⏲️ 개발 기간 
- 2024.12.17 ~ 2025.02.27
  
## 🧑‍🤝‍🧑 개발자 소개 
- **김희수** : 팀장, 백엔드
- **김기렬** : 서기, 백엔드
- **김수경** : 백엔드
- **이승철** : 백엔드
- **주은지** : 백엔드

## 💻 개발환경
- **Version** : Java 17  
- **IDE** : Eclipse
- **Framework** : SpringBoot 3.4.1  
- **Persistence** : JPA, MyBatis  
- **Server** : AWS EC2
- **DataBase** : Oracle
- **WS/WAS** : Tomcat
- **Containerization** : Docker
- **아이디어 회의** : Notion


## 📌 기능
[기능 PPT](https://docs.google.com/presentation/d/e/2PACX-1vTLgZanPxII-VW8GstjqZVlSabxmOVV-670Oa47Dj9BjSvdcSbnudj88YOP0Tr6F_o80gSxzWlmQ7pY/pub?start=false&loop=false&delayms=3000)
- 공통
  - 공통 코드 관리: 시스템 전반에서 사용되는 기준 코드를 효율적으로 관리하여 일관된 데이터 처리를 지원합니다.
  - 로그 관리: 시스템 사용 및 데이터 변경 내역을 기록하여 문제 발생 시 신속한 원인 분석 및 대응이 가능합니다.
- ERP
  - 인사 관리: 인사 정보 등록, 현황 관리 및 인사 발령을 처리하여 조직 내 인력 관리를 최적화합니다.
  - 근태 관리: 연차 및 휴일 등록, 휴가 조회, 근로 시간 관리 및 출퇴근 현황을 체계적으로 관리합니다.
  - 급여 관리: 급여 지급 이력 조회, 급여 이체 처리 및 급여 관련 코드 관리를 통해 정확한 급여 처리를 지원합니다.
  - 영업 관리: 수주, 발주 및 출하 관리를 통해 고객과의 거래를 효율적으로 지원하고 관리합니다.
  - 전자 결재: 내부 의사결정 프로세스를 디지털화하여 빠르고 투명한 업무 처리를 가능하게 합니다.
- MES
  - 기준정보 관리: 품목, 거래처, 창고, 설비, 공정에 대한 정보를 정확히 관리하여 생산 공정의 정확성을 높입니다.
  - 자재 관리: 자재 재고 관리, 입출고 현황을 실시간으로 파악하여 자재 손실을 최소화합니다.
  - 생산 관리: BOM 관리, 생산 계획 수립, 작업 지시 관리 및 로트 추적을 통해 생산 과정의 투명성과 품질을 보장합니다.
